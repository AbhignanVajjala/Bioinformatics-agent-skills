# Contributing

Read AGENTS.md and docs/authoring-guide.md. Keep scientific changes narrow and supply
positive, invalid-input and boundary cases. State tool versions, data licenses,
experimental unit, assumptions and expected claims. Run the documented offline checks.
Do not include patient data, archive-derived text of uncertain license, secrets, or
unverified citations. Submit evidence paths with claims; disclose AI-assisted authorship
and actual reviewers. Record contributions in the PR and version history.

All initial skills are experimental. Reviewed requires a named relevant human methodological
review with scope and unresolved findings recorded. Validated additionally requires a
versioned evaluation protocol, independent evidence, and explicit scope; passing structural
checks alone cannot promote maturity. Maintainers do not certify clinical applications.
Version incompatible artifact or method changes explicitly and document migrations.
