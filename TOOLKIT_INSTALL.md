# Executable toolkit installation

Extract the toolkit into a new directory and open a terminal at its root.
Use Python 3.12 and an isolated environment. The following commands work with
the environment's Python after activation.

```text
python -m venv .venv
python -m pip install -r requirements-toolkit.txt
python -m pip install . --no-deps
python examples/expanded/run.py --output first-use-output
python -m bioskills --help
```

Activate with `.venv\Scripts\Activate.ps1` in PowerShell or
`. .venv/bin/activate` on Linux. Alternatively use that environment's Python
executable directly for every command. Scientific dependencies are downloaded
only by the explicit install command. The package vendors no scientific binaries
or third-party libraries.

The first-use output contains actual synthetic pseudobulk counts, sample
metadata, Fisher/BH ORA results, a FASTQ inspection report and hashed execution
provenance. Choose a new output directory for each run.
[Validator commands and exit codes](docs/validators.md).

For the optional R recipes, install R 4.4.3 and the versions specified in
`recipes/rnaseq/environment.json`. Install jsonlite 1.8.9 and BiocManager
1.30.25 from their official CRAN source archives, then run
`Rscript recipes/rnaseq/install.R` from the toolkit root. This explicit
installation uses Bioconductor 3.20. Run `Rscript recipes/rnaseq/test.R`
to generate and fit the synthetic RNA-seq fixtures with DESeq2 and edgeR.
It requires a fresh `artifacts/rnaseq-ci` output path.

COBRApy needs a functioning GLPK/libsbml installation. If your platform blocks
the native dependency, record BLOCKED and use an approved supported environment.
On a read-only home, direct `XDG_CACHE_HOME` and `MPLCONFIGDIR` to writable
task-local folders before running the scientific examples.

For instruction installation and host compatibility, follow [INSTALL.md](INSTALL.md).
All models and data generated by these first-use recipes are synthetic. No
clinical validation, causal inference or real-world model performance is claimed.
