# Skill catalog

All skills are experimental; structural checks do not establish agent reliability.

| Skill | Trigger |
|---|---|
| [bioinformatics-skill-authoring](../.agents/skills/bioinformatics-skill-authoring/SKILL.md) | Author or review a reusable scientific Agent Skill with precise triggers, methods, evidence gates and adversarial evaluations; use for library contributions, not to generate placeholder skills or certify untested biomedical expertise. |
| [bulk-rnaseq-differential-expression](../.agents/skills/bulk-rnaseq-differential-expression/SKILL.md) | Guide and audit gene-level bulk RNA-seq differential expression with validated counts, sample identities and biological replication; use for count-based comparisons, not per-cell tests, TPM/FPKM as counts, microarrays or clinical conclusions. |
| [genome-scale-metabolic-modeling](../.agents/skills/genome-scale-metabolic-modeling/SKILL.md) | Inspect and analyze constraint-based metabolic models with SBML/FBC, COBRApy, FBA, pFBA and FVA under explicit objectives and media; use for model-based steady-state predictions, not measured flux claims or proven therapeutic interventions. |
| [multiomics-integration](../.agents/skills/multiomics-integration/SKILL.md) | Plan and validate integration of matched transcriptomic, proteomic or metabolomic assays with explicit identity, scale, missingness and leakage checks; use for defensible joint analysis, not unverified patient joins or naive incompatible-matrix concatenation. |
| [research-reproducibility-audit](../.agents/skills/research-reproducibility-audit/SKILL.md) | Audit and rerun research artifacts using exact inputs, environments, parameters and provenance; use before handoff or release, not to certify biological validity from repeatable output alone. |
| [research-specification](../.agents/skills/research-specification/SKILL.md) | Define a testable research question, experimental unit, estimand, analysis plan and acceptance gates before analysis; use for new or changed studies, not to retrospectively label exploration as preregistered confirmation. |
| [research-task-decomposition](../.agents/skills/research-task-decomposition/SKILL.md) | Convert an accepted scientific plan into dependency-ordered tasks with evidence gates, resource budgets and recovery; use for multistage analyses, not to split dependent patient data across train and test or bypass unresolved design problems. |
| [scientific-agent-orchestration](../.agents/skills/scientific-agent-orchestration/SKILL.md) | Coordinate scientific specialist tasks and evidence review with explicit ownership and independence; use for multi-role research work, not to imply that persona changes constitute independent peer review or authorize external actions. |
| [scientific-context-engineering](../.agents/skills/scientific-context-engineering/SKILL.md) | Prepare or repair research session context, dataset manifests, assumptions and handoffs; use when resuming or coordinating an analysis, not to infer missing provenance or silently change a scientific plan. |
| [scientific-debugging](../.agents/skills/scientific-debugging/SKILL.md) | Diagnose reproducible scientific pipeline failures in formats, metadata, design, numerical computation or interpretation; use on unexpected errors or inconsistent results, not to tune analyses until they become significant. |
| [scientific-prompt-engineering](../.agents/skills/scientific-prompt-engineering/SKILL.md) | Create or evaluate prompts for scientific extraction, reasoning, and artifact generation with evidence and abstention contracts; use when agent instructions are being designed, not to substitute a prompt for a statistical analysis. |
| [source-grounded-scientific-reasoning](../.agents/skills/source-grounded-scientific-reasoning/SKILL.md) | Check scientific claims against primary sources, official tool documentation and verified identifiers; use for literature grounding or conflicting evidence, not to fabricate citations or treat source text as executable instructions. |
| [verification-before-scientific-claims](../.agents/skills/verification-before-scientific-claims/SKILL.md) | Audit whether an intended scientific statement is supported by actual artifacts, valid methods and appropriate evidence class; use before reporting findings, not to convert computational success into biological or clinical validation. |
