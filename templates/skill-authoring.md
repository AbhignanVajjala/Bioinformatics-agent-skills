# Authoring worksheet (not an installed skill)

Create an original SKILL.md with name/description YAML only after defining these fields.
Replace each instruction below with domain-specific, falsifiable content; this worksheet
is not a ready-to-use scientific skill and is never included in the generated catalog.

1. Trigger/exclusions: give two appropriate tasks and two confusing near-neighbor tasks.
2. Required inputs: organism/reference, assay scale, experimental unit, study design and access.
3. Preflight: identify missing essentials, resource requirements and immutable input hashes.
4. Method decisions: compare established methods with assumptions and rejection criteria.
5. Procedure: list concrete transformations, commands and artifacts with recovery paths.
6. Gates: separate integrity, numerical execution, statistics, biology and provenance.
7. Stops: state non-identifiability, leakage, invalid units and missing-source responses.
8. Outputs: name files and applicable schemas; record NOT_RUN rather than fictitious results.
9. Interpretations: specify supported claims and prohibited overinterpretations.
10. Evaluation: executable positive/negative tests, expected artifacts, trigger cases and rubric.
11. Sources: official URLs, versions, checked dates, unresolved licenses and scientific reviewers.
12. Done: explicit evidence required, with experimental maturity until review warrants more.

Review checklist: valid metadata; resolvable references; original licensed text; no sensitive
fixtures; no fabricated citations; tests actually executed; limitations preserved;
actual review provenance; catalog and implementation status refreshed.
